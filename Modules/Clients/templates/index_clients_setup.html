Setup Instructions
  1. Download the configuration file above if you plan to use the Winget-Repo Client.
  2. Download and install the Winget-Repo Client on your system.
  3. Launch the Winget-Repo Client with administrator privileges, open the Settings page, and click Import config.ini to import the configuration file.
  4. Add Winget-Repo as a Winget source on your system. Make sure to run the command as the same user who will use the client. Administrator privileges are required.
    winget source add -n Winget-Repo -t "Microsoft.Rest" -a https://{{ host_url }}/api/ {% if authentication == '1' %}--header "{{ '{' }}'Token': '{{ client.TOKEN }}'{{ '}' }}"{% endif %}
  5. Launch the client and enjoy using Winget-Repo!
